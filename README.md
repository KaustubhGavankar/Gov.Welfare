🏛️ Government Welfare Scheme Website
🔹 Project Overview

A web-based platform that provides citizens with detailed information about government welfare schemes in a simple and accessible way. The website helps users explore different schemes, understand eligibility criteria, and learn how to apply — bridging the gap between government initiatives and the people.

🔹 Features

📌 Scheme Directory – Central & State government schemes categorized by sector (Education, Healthcare, Agriculture, Employment, Women Empowerment, etc.).

🔍 Search & Filter – Allows users to find schemes based on category, age, occupation, or income group.

✅ Eligibility Checker – Users can enter details to know which schemes they qualify for.

🌐 Responsive Design – Mobile-friendly and easy to navigate for all users.

📊 User-Friendly UI – Minimal and clean interface for accessibility.
